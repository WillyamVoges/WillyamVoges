## Willyam Voges

Desenvolvo software sob medida para empresas, do front-end ao deploy. Meu foco é resolver problemas reais de negócio com sistemas simples de operar, e automatizar tudo o que pode ser automatizado.

- **Sistemas web e plataformas internas**: do levantamento de requisitos à produção
- **APIs e integrações**: conectando sistemas e serviços de terceiros
- **Automação de processos**: tirando tarefas repetitivas das mãos das equipes
- **Banco de dados, infraestrutura e deploy**: aplicações estáveis e fáceis de manter
